Forecasts are saved before kickoff and never rewritten after the result. Checks run on startup and hourly while the server is running. No checks run while the computer is asleep.

Rounds with matches in the next seven days receive forecasts. Missed kickoffs are marked without inventing past predictions. New published results are used to retrain the model for future matches, including both wins and mistakes.
